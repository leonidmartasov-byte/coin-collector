# Міні-гра «Збирач монет»

🔗 **Грати онлайн (GitHub Pages):** https://github.io

У грі реалізовано плавну анімацію руху гравця на HTML5 Canvas за допомогою клавіш WASD або стрілок із прив'язкою швидкості до `deltaTime`. На полі випадковим чином генеруються монети, при зборі яких нараховуються очки та відтворюється короткий звуковий сигнал через Web Audio API. Також працює таймер зворотного відліку на 60 секунд і ворог-переслідувач у вигляді червоного кола з початковою швидкістю 120 px/сек. Кожні 5 зібраних очок збільшують швидкість ворога на 10 px/сек, а зіткнення з ним або закінчення часу завершує гру екраном Game Over. Надалі до проєкту варто додати збереження найкращого результату в `localStorage` та тимчасові бонуси прискорення чи щита для гравця. Крім того, планується реалізувати вибір рівня складності й сенсорне керування для смартфонів.
